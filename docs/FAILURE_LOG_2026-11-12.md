# 시행착오와 검증 기록 — 2026-11-12

이번 범위는 OTA 단계 표시 순서 수정, Pi2 UI 배포, 정상 CAN 동작 확인과
원격 화면 조회다. 실제 OTA·CPU 결함·슬롯 바꿔치기를 연결한 전체 시연은

## 측정 결과와 증거의 범위

화면 수집 수정 후 약 45초 동안 9회 관측했다. 감시 누적 시간은 44.228초,
수집한 7개 창의 지연 p99는 2.19~4.89ms였고 모두 정상 판정·누락률 0이었다.
한 번의 짧은 정상 상태 관측이므로 장시간 안정성이나 CPU 결함 검출 성능을
다시 입증한 결과로 해석하지 않는다.

공개 가능한 원본 관측과 시험 결과는
[검증 증적](verification/2026-11-12-cockpit/README.md)에 보관한다.
화면 PNG와 전체 로컬 작업 산출물은 `.demo/`에 남기며 Git에는 넣지 않는다.
SSH 개인키, 서명 개인키, 계정 및 Wi-Fi 비밀번호는 포함하지 않는다.

## 아직 남은 부분

- 최신 IVI QML 디자인은 소스에 있다. 설치된 V2 슬롯 내부를 직접 수정하지 않았으므로
  해당 디자인을 실제 IVI에 반영하려면 새 payload 빌드·서명·설치가 필요하다.
- 이번에 배포한 것은 콕핏 화면, 상태 수집기와 표시 이력 기능이다.
- CPU 경합 감지 → TCP 복구 슬롯 교체 → 롤백 거부를 연결한 전체 실보드 재시연은 미실행.
- CAN 인증 판정 CLI/relay 옵션은 소프트웨어 시험 대상이며, 보드의 PSK 배포·실경로 검증과 구별한다.
- 실행 서비스와 CPU 분리는 transient 및 `/run` 설정으로 재부팅 후 자동 복원을 보장하지 않는다.
- 원격 조회는 실제 렌더링 화면을 SSH로 전달하는 읽기 전용 조회다. 입력 조작이 가능한 VNC가 아니며
  프레임 주기와 네트워크 지연이 있어 짧은 애니메이션은 건너뛸 수 있다.
